# dialogacore-whatsapp-scheduling-agent
AI-powered WhatsApp agent with RAG and Google Calendar scheduling orchestration.

This repository contains the Google Calendar integration and scheduling orchestration component developed for the Google for Startups AI Agents Challenge. The core DialogaCore platform remains proprietary, while this repository demonstrates the agent's interaction with Google Calendar and scheduling workflows.


The agent's Coexistence vision was not covered in the demonstration video. To complement the evaluation, we have included images and supporting materials in this repository that present this concept and its application within DialogaCore.
